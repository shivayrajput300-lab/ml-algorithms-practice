# ML Algorithms from Scratch 🤖

Implementing core Machine Learning algorithms from scratch using only NumPy.
No sklearn for the algorithm logic — just math and Python.

## Algorithms Implemented

### ✅ Linear Regression
- Gradient Descent approach
- OLS (Normal Equation) approach

## Tech Stack
- Python
- NumPy
- Jupyter Notebook

## Why this repo?
Understanding ML algorithms deeply by building them from scratch
before using library implementations.
